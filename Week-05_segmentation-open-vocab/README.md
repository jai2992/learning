## Learning links

- [ ] [Grounding DINO](https://github.com/IDEA-Research/GroundingDINO): Detect objects from a text prompt
- [ ] [Ultralytics: YOLO-World](https://docs.ultralytics.com/models/yolo-world/): Lighter text-prompted detector that runs on CPU
- [ ] [Grounded-SAM-2](https://github.com/IDEA-Research/Grounded-SAM-2): Reference pipeline: text to box to mask
- [ ] [Hugging Face Computer Vision Course](https://huggingface.co/learn/computer-vision-course): Use the detection and segmentation units as reference
